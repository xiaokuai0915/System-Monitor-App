# System Monitor App 🖥️

A simple lightweight C++ system monitor application built for learning front-end and back-end web development integration.

## 📌 Project Overview
This project demonstrates how to build a web-based system monitor using C++ for backend API routing and event handling, serving static front-end web assets.

## 🛠️ Details
* **Language:** C++
* **Backend Framework:** [Crow](https://github.com/CrowCpp/Crow) (C++ Microframework for Web Services)
* **Asynchronous I/O:** [Asio](https://github.com/chriskohlhoff/asio) (C++ Network & Low-Level I/O Library)
* **Frontend:** HTML, CSS, JavaScript

## 📦 Required Libraries
Make sure to include and link the following libraries in your build setup:
1. [Asio](https://github.com/chriskohlhoff/asio)
2. [Crow Framework](https://github.com/CrowCpp/Crow)
