# System Monitor App 🖥️

> **Status:** 🚧 Work in Progress (Still in active development)

A lightweight C++ desktop system monitor application built for personal learning—specifically to explore how to integrate modern front-end web technologies with a native C++ backend.
---

## 📌 Project Overview

This project serves as a practical hands-on experiment in building a desktop application with a web-based UI. It runs an embedded local web server via a C++ backend to handle routing, API requests, and system data, while rendering the interface through a native webview window.

## 🛠️ Tech Stack & Details

* **Core Language:** C++
* **Desktop UI / Window:** [WebView](https://github.com/webview/webview) (Tiny cross-platform web view library for C/C++)
* **Backend Microframework:** [Crow](https://github.com/CrowCpp/Crow) (Handling web service routing and API endpoints)
* **Asynchronous I/O:** [Asio](https://github.com/chriskohlhoff/asio) (Network & low-level I/O operations)
* **Frontend Interface:** HTML, CSS, JavaScript

---

## 📦 Dependencies & Requirements

To build and run this project from source, ensure you have the following libraries configured in your build environment:

1. [WebView](https://github.com/webview/webview)
2. [Asio (Standalone)](https://github.com/chriskohlhoff/asio)
3. [Crow Framework](https://github.com/CrowCpp/Crow)
